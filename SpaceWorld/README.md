# 3D Space Explorer

A Three.js based 3D space scene that you can navigate using keyboard and mouse controls.

## Features

- **3D Space Environment**: Explore a beautiful starfield with colorful planets
- **Smooth Movement**: Navigate through 3D space using WASD controls
- **Mouse Look**: Click and drag to look around
- **Vertical Movement**: Use Space and Shift to move up and down
- **Responsive Design**: Adapts to window size

## Controls

- **W** - Move forward
- **S** - Move backward
- **A** - Strafe left
- **D** - Strafe right
- **Space** - Move up
- **Shift** - Move down
- **Mouse** - Click and drag to look around

## Getting Started

Simply open `index.html` in a modern web browser. No installation or build process required!

The project uses Three.js from CDN, so an internet connection is needed the first time you load the page.

## Technologies

- Three.js r128
- HTML5
- CSS3
- Vanilla JavaScript
